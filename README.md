# VANTA DETAILING — demo concept

Адаптивный демонстрационный сайт вымышленной студии детейлинга. Показывает услуги по уходу за автомобилем, калькулятор оценки стоимости и форму проверки демонстрационной заявки.

## Стек

- React 19, Vite 7, JavaScript
- Локальные изображения и Manrope Variable
- Playwright и axe-core для браузерных проверок

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Vite выведет локальный адрес (по умолчанию `http://127.0.0.1:5180/`). Production build:

```sh
npm test
npm run build
npm run preview
```

## Что работает

- Каталог услуг с раскрытием описаний.
- Интерактивная оценка стоимости по классу автомобиля и выбранным услугам.
- Переход из калькулятора в демонстрационную форму с заполненной оценкой.
- Валидация полей и подтверждение локального демосценария.
- Адаптивная навигация и макет для мобильных экранов.

## Ограничения демо

Название студии, тарифы и кейсы вымышлены. Форма только показывает состояние интерфейса: она не отправляет, не сохраняет и не передаёт имя или телефон. На сайте нет backend, CRM, реальной записи или оплаты. Не используйте введённые данные как реальную заявку.

Фотографии используются как иллюстрации концепции по Unsplash License, а не как доказательство выполненных работ. Авторы и исходные страницы перечислены в `portfolio/ASSETS.md`; источники также доступны на сайте через страницу `credits.html`.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Для `npm run test:e2e` сначала запустите `npm run dev` в другом терминале и установите Chromium для Playwright (`npx playwright install chromium --only-shell`).
